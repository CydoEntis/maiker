# Features: shipped, declined, later

What Maiker has, what was cut or declined on purpose, and what is deferred. A cut item stays
out until the user re-approves it. Planned work lives in Plane, not here. Moved from the old
roadmap; the phase history stays in `docs/ROADMAP.md` until that file is retired.

## In scope

Existing features below are shipped unless marked. Optional chat GUI and native
conversation continuity are planned in phases 34–37:
[intent](features/chat-gui/intent.md) · [spec](features/chat-gui/spec.md).

**Core**
- Daemon owns sessions; detach / reattach; many clients — shipped — `crates/maitty-core/src/daemon/mod.rs`, ADR 0001
- Sessions survive a daemon restart (agents resumed, commands re-run) — shipped — `crates/maitty-core/src/daemon/persist.rs`, `restore` in `crates/maitty-core/src/daemon/mod.rs`
- Windows (ConPTY, named pipes, PowerShell folder tracking), macOS, Linux — shipped — `crates/maitty-core/src/daemon/term.rs`, `crates/maitty-core/src/ipc.rs`
- SSH remotes (`--remote host`) — shipped — `crates/maitty-core/src/ipc.rs` `connect_remote`

## Out

- In the desktop sidebar: machine headings, status headings and their Show status headings setting, the pinned Needs you strip, count badges on folded headings, and the Put away section with Put away, Bring back, Snooze and Unsnooze — removed 2026-11-22 with the UI overhaul (handoff v5): the list's own order puts what needs you on top, and a session the daemon has put away is listed like any other. Put away stays in the terminal app.
- Saved role profiles and the planner/approval/worker/reviewer workflow runner were removed by user decision (2026-10-18). Use the agent's own configuration and external workflow tools; Maiker remains the session manager. The team list for the commander that phase 17 allowed (2026-10-22) was removed with the commander in phase 19. A Maiker-run pipeline, where Maiker starts or orders stages itself, stays cut. Maiker shows a workflow's specialists working, not the workflow's own steps ([ADR 0010](adr/0010-workflows-and-specialist-agents-stay-outside-maitty.md), [how to use it](workflows.md)).
- In-app tickets: Start from a ticket, its Settings › Tickets, the terminal app's Tickets view, ticket setup (a pasted link, `.maiker/tickets.toml`, the agent's `maitty_tickets_setup`) and the stored Plane and Linear keys — removed 2026-11-17, the user's call: the in-app view was a worse version of Plane, Linear and GitHub Issues ([ADR 0013](adr/0013-no-in-app-tickets.md)). The PR headline and Checks stay; they are not tickets.
- Workflow runs, the Work board, `maiker workflow report`, Send to Factory, and commenting on or closing tickets — removed 2026-11-17, the user's call: they pulled Maiker away from showing which agents need you ([ADR 0011](adr/0011-maitty-reads-tickets-and-shows-no-workflow-runs.md)). The tickets part was superseded: Start from a ticket is gone too (see the next entry). Project crews (a captain agent that drafts tickets and directs crewmates) are dropped with them, and the unmounted `features/crew/` screens are deleted.

- Features cut 2026-10-09 remain out unless re-approved: open project, go to, next agent that needs you, arrange panes, undo automatic workspace, the map, ideas, races, run a preset as a list (presets stay in the new-agent dialog), past chats, agent tools, extensions, and the tmux stand-in for Claude agent teams.
